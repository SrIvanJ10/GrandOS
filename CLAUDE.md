# Instrucciones para peticiones de código

Cuando te pida código o implementaciones:

1. **ANTES de generar código**, si hay ambigüedad sobre:
   - Librerías/frameworks a usar
   - Estándares de lenguaje (versiones)
   - Estructura de archivos o módulos
   - Dependencias externas
   - Scope de funcionalidad
   
   Pregúntame sobre estos puntos específicos. No asumas.

2. **Formato de respuesta:**
   - Primero: Tus preguntas clarificadoras (si las hay)
   - Luego: El código con comentarios breves
   - Siempre: Menciona qué librerías/dependencias usa

3. **Criterio de atomicidad:**
   - Si lo que pido parece que necesita 2+ responsabilidades distintas, 
     señálalo y propón dividirlo
   - No generes código "inflado" con funcionalidad extra

4. **Contexto:**
   - Si menciono un proyecto específico, asume que hay un README.md 
     o estructura clara que deberías preguntarme si no conoces
